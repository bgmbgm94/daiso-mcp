# 9월 유지보수 설계

사용자는 2026-09-15 점검 보고서의 모든 유지보수 진행을 승인했습니다.

## 범위와 완료 기준

1. MCP smoke는 오류 text를 JSON으로 해석하기 전에 isError를 확인하고 원인을 보존합니다. 계정 정지·설정 오류는 재시도 가능 장애와 구분합니다. 정상 응답 계약은 유지합니다.
2. Zyte 정지 사유와 GS25 인증 상태를 확인하고 CU·이마트24·CGV의 공식 요청 경로를 조사합니다. 확인된 무료 직접 경로가 있으면 복구하고, 없는 경우 명시적 조회 불가를 유지합니다. 비용 한도 상향이나 새 과금 계약은 포함하지 않습니다.
3. 의존성 PR 10건을 최신 main과 비교해 이미 반영된 항목을 정리하고 호환 가능한 갱신을 검증합니다. 메가박스 CLI와 디트릭스 PR은 코드·테스트·문서 검토 후 가능한 범위를 통합합니다.
4. 정적 검사, 모든 테스트, 네 지표 100% coverage, audit, 빌드, 패키지 dry-run, 독립 리뷰를 통과한 변경을 GitHub에 반영합니다. 릴리스 커밋과 태그를 일치시키고 npm 게시를 검증합니다. 배포 후 기존 운영 체크를 다시 확인합니다.

## 접근

단순 의존성 갱신만으로는 운영 장애가 해결되지 않습니다. 반대로 유료 우회 확대는 기존 비용 결정을 위반합니다. 오류 원인을 보존하는 작은 수정, 검증된 공식 직접 경로 복구, 호환 의존성 통합을 순차 반영합니다. 장애를 빈 성공으로 숨기거나 확인되지 않은 인증키를 생성하지 않습니다.

## 구조와 검증

기존 scripts/ops/mcp-smoke.ts, src/core/errors.ts와 대응 테스트를 우선 수정합니다. 서비스 수정은 해당 client/api 모듈에 제한하고 450줄을 유지합니다. 오류 회귀는 실패 테스트를 먼저 작성하고 통과시킵니다. 외부 계정 사유와 코드 결함을 분리해 기록합니다. 외부 제약 때문에 실제 조회를 복구하지 못한 경우에는 검증 결과와 남은 조건을 명시합니다.
